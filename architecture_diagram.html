应用层（TCP服务器）

tcp_server.exe / udp_server.exe / web_server.exe / icmp_server.exe

↓ 调用 net_init()

协议栈核心模块

① 数据采集层（5个关键位置）

  • ethernet.c - 以太网帧收/发统计
  • ip.c - IP数据包收/发统计
  • tcp.c - TCP分节收/发统计
  • udp.c - UDP数据报收/发统计
  • icmp.c - ICMP消息收/发统计

② 统计聚合层（protocol_stats.c）

  • 维护5个全局统计结构体
  • 提供protocol_stats_to_json()序列化函数
  • 支持实时动态数据导出

③ 监控服务器（monitor_server.c）

  • TCP服务器 (127.0.0.1:9999)
  • 支持最多10个并发客户端
  • 多线程事件驱动处理模型
  • JSON格式数据推送
- 数据流: 各层采集 → 全局计数器 → JSON序列化 → TCP推送
↓ JSON over TCP (端口9999)

可视化客户端（Python）

monitor_gui.py (Tkinter + Matplotlib)

- 实时监控面板（6个子图）

  • IP数据包趋势（发送/接收）
  • TCP数据包趋势（发送/接收）
  • UDP数据包趋势（发送/接收）
  • ICMP数据包趋势（发送/接收）
  • 以太网帧趋势（发送/接收）
  • 协议分布饼图

- 统计信息面板（5层数据）

  • 以太网：包数、字节数、错误
  • IP层：包数、字节数、错误
  • TCP层：分节数、字节数、错误
  • UDP层：数据报数、字节数、错误
  • ICMP层：消息数、字节数、错误
- 更新频率: 1秒轮询一次 | 显示范围: 实时滚动50秒数据窗口
